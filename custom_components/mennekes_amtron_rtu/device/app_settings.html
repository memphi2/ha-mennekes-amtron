Adapter serial settings

Saving applies the selected TCP port, connection mode, login and serial settings to the adapter immediately. Its existing web password is not changed.

This changes the app connection only. To enable or disable login on a compatible adapter, first read its settings and select “Apply adapter settings when saving”.

Login does not encrypt the traffic. Firmware 1.523 allows bypassing it; use a protected local network.

Saving keeps the current connection running. Restart the app afterwards to apply the change; this briefly interrupts its heartbeat.

Available to Home Assistant administrators with Supervisor 2026.10.4 or newer. No service token is needed here.
