USB adapter

Choose your adapter from the list. Stable device names are preferred automatically; an adapter is never selected for you.

Speed and data format must match the wallbox; factory defaults are 57600 baud and 8N2. Changing these app settings does not reconfigure the wallbox.

LAN adapter

Enter the LAN adapter address without http:// or a path. Use its configured TCP port, commonly 502. The Modbus service’s HTTP port 8765 does not belong here.

Set the serial baud rate and format on the LAN adapter. Saving LAN settings removes any old USB adapter selection.

Adapter serial settings

Saving applies the selected TCP port, connection mode, login and serial settings to the adapter immediately. Its existing web password is not changed.

This changes the app connection only. To enable or disable login on a compatible adapter, first read its settings and select “Apply adapter settings when saving”.

Login does not encrypt the traffic. Firmware 1.523 allows bypassing it; use a protected local network.

This number identifies the wallbox on the RS-485 bus, including behind a LAN adapter. Factory default: 50; supported range: 10–50. It is not an IP address.

Saving keeps the current connection running. Restart the app afterwards to apply the change; this briefly interrupts its heartbeat.

Live Modbus communication

Optional troubleshooting: observe existing reads, writes and heartbeats for up to 10 minutes. Only the latest 200 entries stay in memory; nothing is stored in the Home Assistant database or log files.
